# Geographical Artificial Intelligence Analysis (gAIa)

gAIa is a geospatial AI project exploring how satellite imagery and machine learning can be used to analyze land-use and environmental change.

> **Note: `main` is a prototype branch.** It contains an experimental implementation and is not the primary version of the complete application. The machine-learning model and production frontend are maintained separately in their respective branches.

## Repository Structure

The project is divided across three primary branches:

| Branch | Purpose |
|---|---|
| [`main`](https://github.com/vikram-saraswatula/veritasEEpipeline/tree/main) | Experimental prototype and early implementation |
| [`model`](https://github.com/vikram-saraswatula/veritasEEpipeline/tree/model) | Machine-learning model and imagery-processing pipeline |
| [`prod`](https://github.com/vikram-saraswatula/veritasEEpipeline/tree/prod) | Production frontend and integrated application |

## Where to Find the Project

### Machine-Learning Model
Visit the [`model` branch](https://github.com/vikram-saraswatula/veritasEEpipeline/tree/model) for the machine-learning implementation, including the model and its associated processing pipeline.

### Production Frontend
Visit the [`prod` branch](https://github.com/vikram-saraswatula/veritasEEpipeline/tree/prod) for the current frontend, application interface, and integrated geospatial analysis experience.

### Prototype
The `main` branch preserves an earlier experimental version of the project. It is useful for understanding the project's initial development, but it should not be considered the latest or complete implementation.

## Development

Development is organized by component:

- **Model development:** `model`
- **Frontend and application development:** `prod`
- **Prototype and experimentation:** `main`

For the latest project implementation, refer to the `model` and `prod` branches rather than relying on the prototype in `main`.
